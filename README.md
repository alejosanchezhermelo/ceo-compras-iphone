# CEO Compras (iPhone)

App de iPhone para consultar las órdenes de compra de CEO Construcciones, con entrada por Face ID.
Lee la misma base que la app web. Etapa 1: solo lectura.

Se compila sola en GitHub Actions y se instala con SideStore:
